# WubiLexTool — 需求文档集

> 面向 **Rust + Tauri 2 + React 19 + Tailwind CSS v4** 重写版本的需求规格。
> 分析对象：`wubi-lex/`（aardio 实现的 WubiLex 五笔助手 v12.1，32 个源文件 / 7,574 行）。

---

## 这套文档是什么

原项目 WubiLex 是一个用 aardio 编写的 Windows 桌面工具，用于**替换和管理 Windows 自带微软五笔输入法的码表与短语词库**，并提供反查拆字、字根图、输入法设置等配套能力。

本文档集把原项目的全部行为拆解为**可实现、可验收、可追溯**的需求条目，供新项目 **WubiLexTool** 直接驱动开发。

**关键约束**：目标平台限定为 **Windows 独占**（Win10 1703+ / Win11）。原项目深度耦合 TSF、注册表、TrustedInstaller ACL 与微软五笔 IME，本文档不做跨平台抽象。

## 需求 ID 规则

格式：`<模块>-<域>-<三位序号>`

```
M1-PARSE-004
│  │     └── 模块内域段下的序号，永不复用
│  └──────── 功能域缩写
└─────────── 模块编号 M1..M8
```

- ID 一经写入即**冻结**。需求作废时保留 ID 并标注「已废弃」，不得回收再用。
- [`22-roadmap.md`](./22-roadmap.md) 以 ID 为主键做交叉引用。
- 横切需求另用 `NFR-*`（非功能）与 `UX-*`（界面）前缀。

## 优先级定义

| 级别 | 判据 | 典型内容 |
|---|---|---|
| **P0** | 缺失则产品不成立 | 码表解析/编辑/安装主链路、短语读写、反查基础查询、输入法启停、应用外壳最小闭环 |
| **P1** | 显著影响体验，可延后 | 格式转换、精简、词频优化、造词、笔顺动画、字根图、双拼、在线目录 |
| **P2** | 锦上添花，或依赖外部不可控资源 | 手写输入、语音输入、第三方联想 API、Windows 技巧文本 |
| **P3** | **不实现**，仅历史记录 | ImTip 集成、原项目中已废弃或未接线的代码 |

## 首要原则

> **旧项目是行为规格，不是实现范本。**

原项目 WubiLex 在本文档集中只承担一个角色：**说明「正确的行为是什么」**。它不说明「该怎么写」。

- 需求条目的「来源」列指向的代码，是**行为的权威定义**，不是要移植的实现
- 遇到更优的实现方式，**直接用更优的**，不必与原实现保持形似
- 只有 [`02-architecture.md#0.1`](./02-architecture.md#01-什么必须一致行为契约) 列出的 **12 条行为契约**必须逐位一致 —— 改了会让用户现有的码表/短语出错，或让系统不工作
- 其余一切（数据结构、算法、并发、错误处理、UI）**自由**
- 已定案的 **24 项更优实现**见 [`02-architecture.md#0.3`](./02-architecture.md#03-已识别的更优实现)

**UI/UX 完全重新设计**，不承接原项目的结构、配色与交互，见 [`21-ui-ux.md`](./21-ui-ux.md)。

## 可追溯性约定

- 每条需求的**来源**列指向 `wubi-lex/` 下的真实文件 —— 用于**查证行为**，不是移植目标。
- 行为描述**以源码实际逻辑为准**。原项目 README 的宣传措辞与代码冲突时以代码为准，并在备注中记录冲突。
- [`00-overview.md`](./00-overview.md) 的源文件覆盖表保证 32 个 `.aardio` 文件零遗漏。
- [`03-source-index.md`](./03-source-index.md) 提供**反向索引**：从源码位置查到它定义了哪些行为。
- 每个模块文档末尾有「源码索引」章节，提供**正向索引**：从功能域查到行为定义位置，并附「⚠️ 不要照抄的位置」。
- 标注 **【新增】** 的需求原项目无对应实现，不必去找参考。

## 维护约定

1. **新增需求**：在对应模块文档的域段末尾追加，序号递增；同步更新 `22-roadmap.md` 汇总表。
2. **修改需求**：直接改描述，ID 不变；若语义发生实质变化，作废旧 ID 另开新 ID。
3. **数据格式变更**：只改 `01-data-formats.md`，模块文档通过引用指向，不复制格式细节。
4. **风险变更**：统一维护在 `02-architecture.md` 的风险登记册，模块文档只做引用。
5. **发现更优实现**：追加到 `02-architecture.md#0.3` 的表格；若涉及行为契约，先在 `#0.1` 确认是否允许改动。
6. **源码索引**：`wubi-lex/` 是只读的历史快照，行号不会变动，索引一次写对即长期有效。

> ⚠️ [`21-ui-ux.md`](./21-ui-ux.md) 于 2026-08-21 按「全新设计」决策整体重写，此前版本的 `UX-*` 编号已作废。
