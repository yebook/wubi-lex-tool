### 简洁版虚拟键盘的设计理念

原作者在 README 第 25 行阐述的产品观点，应在新 UI 中延续：

> 我们一般看到的五笔字根图都是包含所有按键字根的全图，但是这种字根图会让人眼花缭乱，如果我们的眼睛看到的内容越多，记忆效率就会越低。所以我制作了这种简洁版的虚拟键盘。

即：**完整字根图**（本模块）用于系统性学习，**简洁虚拟键盘**（[M3](./M3-reverse-lookup.md)）用于即时查询。两者互补，不可合并。

### 附录 B：微软五笔使用技巧（`wubi.aardio:19-39`）

1. **Win + 空格**：切换输入法。
2. **短按 Shift**（或 **Ctrl + Space**）：切换五笔中英文输入模式（并自动切换到小写）。
   英文模式、或中文模式下切换到英文标点后可按 **Shift + 空格** 切换全角/半角输入。
   中文模式可使用小键盘输入小数点（不是句号）。
3. **Alt + Shift**：切换中文/英文键盘。
4. **Ctrl + .**（中文模式下）：切换中英文标点。
5. 五笔编码自第二码开始可使用 **Z 键通配任意编码**（首码除外）。
6. 候选窗打开状态下，按 **Tab** 再按 **空格** 可打开「表情与符号面板」。面板有「保持打开」按钮；也可按 **Win + .** 打开系统符号面板。
7. 输入时：**回车** 取消输入，**空格** 取首个候选，**分号 `;`** 取第二个候选，**引号 `'`** 取第三个候选。
8. 输入时按 **`-`** / **`+`** 对候选词翻页。

> 原项目附注（`README.md:32`）：Win10 2004 以上版本已可关闭 Shift、Ctrl+Space 等快捷键。
