# wubilex-learn

> M8 自学习：从语料或实际输入中发现新词，自动补入词库。

> ## ⚠️ 三条状态声明
>
> 1. **优先级 P2**，整体后置。
> 2. **所属阶段 S8**（v1.1），在 S0–S7 全部完成之前不动这里。
> 3. **S8 前不列入 workspace members**（`docs/02-architecture.md` D10）—— 本 crate 会拖入 `jieba-rs`（内置词典约 5 MB）与 UIA 绑定，那是 S0–S7 全程用不到的编译负担。目录先占位，是为了让分层边界从第一天就可见。

## 职责

| 目录 | 内容 | 需求 |
|---|---|---|
| `src/corpus/` | **路径 A**：语料导入与文本提取 | `M8-CORPUS-*` |
| `src/capture/` | **路径 B**：UI Automation 输入采集 | `M8-CAPTURE-*` |
| `src/segment/` | 中文分词 + N-gram 新词发现 | `M8-LEARN-001` |
| `src/store/` | 候选池、频次计数、阈值判定、时间衰减 | `M8-LEARN-002..006` · `M8-MANAGE-*` |
| `src/apply/` | 造码与入库决策 | `M8-APPLY-001..003` |

**采集层（`capture/`）与学习层（其余）必须分离**，使学习逻辑可脱离 Windows 单测。

## 允许依赖

`wubilex-core`、分词 crate（`jieba-rs`）、UI Automation（`windows` 的 `Win32_UI_Accessibility`）。

## 禁止依赖

Tauri、**直接写系统文件**。

入库时把结果交给 `wubilex-core` 的 `PhraseSink`（S3 缝），由其经**短语库**路径写入 —— 不碰系统码表（`M8-APPLY-004`）。

## 对应需求域

`M8-CORPUS` · `M8-CAPTURE` · `M8-LEARN` · `M8-APPLY` · `M8-MANAGE` · `M8-PRIV`

## 所属阶段

**S8 — 自学习 → v1.1**。

## 路径 B 的准入门槛

路径 A（语料导入）没有特殊门槛。**路径 B（输入采集）在动工前必须先满足 `R45` / `R46`** —— 这两条都是极高风险，因为它会记录用户在**所有应用**中的输入：

| 风险 | 门槛 |
|---|---|
| `R45` 全局输入被记录 | 默认关闭 + 显式授权 + **只存分词结果**（不存原文）+ 本地加密 + 一键清除 |
| `R46` 密码 / 敏感内容误采 | 密码框检测 + 进程黑名单 + 窗口标题黑名单 |

**建议先只做路径 A**。语料导入能覆盖大部分「补充个人高频词」的诉求，且完全不触碰这两条风险，也不会被杀毒软件判为可疑行为（`R50`）。

## 其余已登记风险

`R47` 采集覆盖面不完整 · `R48` 自动入库污染词库（默认确认模式 + 只占空码位 + 可撤回）· `R49` 分词质量 · `R51` 频繁写库触发输入法反复重载 · `R52` 采集拖慢输入（延迟预算 < 1 ms）。

完整表见 [`docs/02-architecture.md`](../../docs/02-architecture.md) §10 的「M8 自学习」小节。
